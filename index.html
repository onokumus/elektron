Features

Technical Prestige

Inspired by Linear and Vercel aesthetics - deep blacks, thin borders, and high-contrast typography.

Glassmorphism

Elegant use of background blurs and translucent layers for depth.

Editorial Typography

Lightweight fonts and wide tracking for an authoritative, premium feel.

Micro-animations

Fluid transitions and subtle hover effects for a responsive user experience.

Quick Start

1. Install (NPM)
npm install elektron
2. Add CSS
@import "elektron/style.css";
3. Initialize Sidebar
import { initSidebar } from 'elektron'; initSidebar();
4. CDN (No Build)
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/elektron/lib/elektron.css">
<script type="module">import { initSidebar } from 'https://cdn.jsdelivr.net/npm/elektron/lib/elektron.js'; initSidebar();</script>
